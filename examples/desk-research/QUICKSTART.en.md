# Agent Builder Quick Start

Follow the [developer Quick Start](https://musegea.com/developers/agent-builder-quick-start), from Project creation through implementation, evaluation and iteration with a coding agent.

This repository provides the [runnable project](README.md), [quality iteration history](iterations/README.md) and [cases and scoring criteria](BENCHMARKS.md).

Local model calls use a CR API key directly: inject it as `CREATIVE_REASONING_API_KEY` through your local credential manager, use `creative-reasoning-1.5` for the Agent, Judge, and Simulator, and explicitly select `modelSource: "local"`. See [setup](README.md#配置-cr-api-key).
