通过 queryRun/readEvidence 检查 search_sources 的实际调用结果与最后简报。1 分：至少一次成功检索取得可用正文，主要事实与引用能在返回正文中找到支持，来源局限已说明，没有伪造引用。0 分：没有有效检索、编造事实/引文，或主要结论与引用正文不符。不能仅检查链接存在。空结果/网络失败且无资料不通过证据覆盖，但如实说明不应被指为编造。Judge 无权访问外网，只评价此次捕获的证据；读取失败或证据超限应报 error，不能猜测通过。

先核对三个最重要的事实，逐条记录“报告原句 → 实际返回的来源摘录”。标题、链接和 60 字搜索摘要不能证明未返回的全文内容；没有逐项对应的引用不能凭主题相似视为支持。观察学生、减脂博主、营销账号的摘录时，不得当作城市通勤者的整体事实。若报告只在末尾罗列来源、无法识别关键结论的支持材料，或来源没有支持核心事实，给 0 分。

通过 submitEvaluation 提交结果，严格遵循工具 schema。status 使用 completed、not_applicable 或 error（不是 passed/failed）；score 仅在已完成判定时填写 0 或 1。reason 放文字解释，evidence 是实际读取到的证据引用对象数组，不能填字符串、伪造 messageId 或把解释文字塞入 evidence。判据失败是 completed + score=0；读取失败或无法执行才是 error。
