Baseline 的回答暴露了事实与来源错配、个案结论扩大等风险。先从最终回答和 Judge 理由入手，明确输出要求：关键事实逐条核对来源，结论限定到实际人群和样本，推断写成待验证假设。

本轮只改变研究指令，搜索、正文读取和存储工具保持不变。
